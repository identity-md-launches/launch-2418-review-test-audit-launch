# Current admission reproduction

These four suites reproduce the four pinned `univ4_hook` protected inputs supplied to this
assignment: Hook (4 checks), Owners (2), OwnToken (3), and Token (7). They are ordinary
repository files and have no dependency on `.imd/reads`, RPC, FFI, downloaded packages or
process environment variables. Both token orders run all 16 checks; Hook and Owners also
run their six checks with a different PoolManager address. No admission test skips.

The production contracts and configuration are unchanged. The port makes these adaptations:

- Imports use the repository's existing `@uniswap/v4-core` remapping. This pinned v4 version
  defines `SwapParams` and `ModifyLiquidityParams` inside `IPoolManager`, so the type names
  are qualified accordingly. ABI field order is unchanged.
- Environment reads become explicit test inputs: chain 4663, flags `0x2040`, LP fee 12500,
  spacing 60, fixed supply `1e27`, decimals 18, explicit owner and factory probe roles,
  and the original below/above IMD opening prices. Constructor code includes the supplied
  manager, then owner, then factory. These probe addresses are offline fixtures only.
- The missing `HookFlags`, `MockERC20`, `Swapper`, and `OwnerChecks` dependencies are
  implemented locally in `AdmissionSupport.sol`. Flags come from the vendored v4 library;
  the swapper settles within a single unlock; owner checks require the exact explicit
  owner and reject both the factory and launch origin. The helper also checks that launch
  did not bind or enable the hook. No reference helper unavailable in the inputs is claimed
  to be reproduced byte for byte.
- The vendored forge-std lacks `fail(string)`, so the inputs base supplies the equivalent
  reverting overload. Runtime opcode scans and the protected behavioral assertions are
  retained.
- Creation bytecode is read with `vm.getCode` from artifacts generated by the current
  build. This avoids embedding PoolManager, hook, token and fixture actor constructors in
  every derived test contract. The PoolManager constructor still executes at the supplied address, which
  preserves its `NoDelegateCall` immutable; hook CREATE2 deployment and constructor arguments
  are unchanged. No prebuilt bytecode or network download is needed.
- A missing prerequisite or failed initialization/seeding reverts rather than skipping.
  Both swaps preceding fee collection must succeed rather than having their errors ignored.

The OwnToken floor deliberately exercises a generic split with 50% seeding. This tests
transfer behavior; it does not certify the launch's 80/10/10 factory economics. The existing
`IMDirectorLaunch.fork.t.sol` remains the separate real-factory rehearsal for that policy.
A copied test suite is a local reproduction, not a substitute for independent protected
admission run by the verifier.

Run all local admission checks:

```sh
forge test --offline --match-path 'test/admission/*.t.sol' -vv
```
